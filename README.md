# Dimpho Mphahlele - Virtual CV

**Live URL:** https://dimphomphahlele.github.io

## Overview
This is my personal portfolio website (Virtual CV) created for my BSc Information Technology assignment. It showcases my technical skills, academic projects, personal projects, and achievements.

## Technologies Used
- **HTML5** - Structure
- **CSS3** - Styling, animations, and responsive design
- **JavaScript** - Dark/Light mode toggle and card animations
- **Font Awesome** - Icons

## Sections Included
1. **Hero/Profile** - Introduction with a downloadable CV button.
2. **About Me** - My background and career focus.
3. **Technical Skills** - Categorized into Languages, Frameworks/Tools, and Methodologies.
4. **Projects** - Divided into Personal Projects (QR Generator, FinTech Ledger) and Academic Projects (NGO System, MoneyMind App).
5. **Achievements** - Geekulcha Hackathon 2nd Place win.
6. **Contact** - Email, phone, and social links.

## Setup & Deployment
This project is hosted using **GitHub Pages**. To run locally, simply clone the repository and open `index.html` in your browser.

## Repository Structure
- `index.html` - Main portfolio file.
- `profile.png` - Profile picture.
- `Dimpho_Mphahlele_CV.pdf` - Downloadable resume.
- `README.md` - This documentation file.
